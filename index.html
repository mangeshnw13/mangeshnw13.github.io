Authorized Publishing Integrations

Official OAuth 2.0 and Graph API integrations scoped strictly to the owner's own channels and pages.

YT

YouTube Data API v3

Uploads locally generated 2D animated videos along with titles and descriptions to the owner's YouTube channel using the https://www.googleapis.com/auth/youtube.upload scope.

IG

Instagram Content Publishing API

Publishes the owner's 2D animated Reels and captions directly to the owner's linked Instagram Business or Creator account via official Meta Graph APIs.

FB

Facebook Reels Publishing API

Publishes short-form animated Reels and captions to the owner's authorized Facebook Page with zero third-party viewer data collection.

How the Local Pipeline Works

End-to-end local execution with strict credential isolation and automatic file cleanup.

Step 01

Local Asset Generation

Generates scripts (script.txt), voiceovers (voice.wav), metadata (meta.json), and rendered 2D videos (video.mp4) locally on Ubuntu.

Step 02

Authenticated Upload

Uses locally stored OAuth 2.0 tokens (youtube_token.json and .env) to upload content strictly to owner-authorized channels and pages.

Step 03

Automatic Cleanup

Temporary job files (script.txt, assets.txt, voice.wav, meta.json, video.mp4) are automatically removed prior to each scheduled run.

All OAuth credentials stay on the owner's local machine—never sent to external databases, sold, or shared. Review our full Google API Services Limited Use disclosure, Meta data deletion instructions, and Terms of Service.

Part 1 Privacy Policy

1. Overview

n8n is a private, self-hosted automation workflow operated solely by its owner on a local Ubuntu machine. It automates the creation and publishing of the owner's own 2D animated short-form videos to the owner's authorized YouTube channel, Instagram Business/Creator account, and Facebook Page. This application is not offered to the general public and does not accept third-party user sign-ups.

2. Information Accessed and Processed

Because this tool is used exclusively by its owner, it processes only the following data required to publish the owner's videos:

  • Authorization Credentials: OAuth 2.0 access and refresh tokens granted by the owner for YouTube Data API v3 (https://www.googleapis.com/auth/youtube.upload) and Meta Graph APIs (Instagram Reels and Facebook Reels publishing).
  • Content & Metadata: Locally generated video files (video.mp4), voiceover audio (voice.wav), scripts (script.txt), titles, descriptions, and hashtags (meta.json) created by the owner for upload.

We do not collect, store, read, or process personal data from YouTube viewers, Instagram followers, Facebook visitors, or any other third-party users.

3. Storage, Retention, and Security

  • Local-Only Storage: OAuth tokens and configuration files are stored strictly on the owner's local machine. No external servers, cloud databases, or third-party analytics services receive or store these credentials.
  • Automatic Cleanup: Temporary job files (script.txt, assets.txt, voice.wav, meta.json, and video.mp4) are automatically deleted from the local working directory prior to each scheduled run.
  • No Sharing or Selling: No data accessed through Google, YouTube, or Meta APIs is sold, rented, shared with third parties, or used for advertising or profiling.

4. Google and YouTube API Services Disclosure

This application uses YouTube API Services solely to upload the owner's videos, titles, and descriptions to the owner's own YouTube channel.

  • Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • By using YouTube features through this workflow, the owner agrees to be bound by the YouTube Terms of Service and acknowledges the Google Privacy Policy.
  • Revoking Access: Access to the Google account can be revoked at any time via Google Account Permissions and by deleting the local youtube_token.json file.

5. Meta (Instagram and Facebook) API Disclosure & Data Deletion

This application uses the Instagram Content Publishing API and Facebook Reels Publishing API solely to publish the owner's videos and captions to the owner's linked Instagram account and Facebook Page.

  • Revoking Access & Data Deletion: Access can be revoked at any time in Facebook Business Integrations settings. Because all tokens and temporary files reside strictly on the owner's local machine, deleting the local .env and working directory files immediately erases all stored data. For any data deletion inquiry, email bloggermafia007@gmail.com.
